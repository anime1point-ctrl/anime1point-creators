🔒 Your key is encrypted & never exposed

Your API key is sent over HTTPS directly to our secure Cloud Function, which encrypts it with AES-256-GCM before storing it. It is never stored in plain text and never returned to any browser. Only our Cloud Function uses it to fetch your video data.

How to get a free API key:

  1. Go to Google Cloud Console and create a free project.
  2. Enable the YouTube Data API v3.
  3. Go to Credentials → Create Credentials → API Key.
  4. (Recommended) Restrict the key to YouTube Data API v3 only.
