📝 Pending Creator Applications

Review and approve or reject new creator registrations. Approving copies the application into the live creators collection and activates their YouTube feed.

🔑 About the Application Flow

Creators apply via creatorApplications/{uid} (this queue).
On approval, their profile is copied to creators/{uid} (the live feed collection).
Their encrypted API key is transferred at the same time — the key is never shown in plain text, not even here.
